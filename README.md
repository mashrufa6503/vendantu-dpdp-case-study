# Trust By Design

## Product Management Case Study

*Designing a DPDP-Compliant Student Data Consent Experience for Vedantu*

---

## Problem Statement

Parents often consent to student data collection without clearly understanding what data is collected, why it is needed, or how it will be used. This creates a lack of transparency and trust.

---

## My Solution

I designed a privacy-first consent experience that helps parents make informed decisions through:

- User Research
- Persona Creation
- User Journey Mapping
- Problem Identification
- Low-Fidelity Wireframes
- High-Fidelity Figma Prototype
- Privacy Dashboard
- Consent Management Flow

---

## Features

- Clear consent explanations
- Granular permission controls
- Parent-friendly language
- Privacy Dashboard
- DPDP-compliant design
- Transparent data usage

---

## Tools Used

- Figma
- Microsoft PowerPoint
- Product Thinking
- UX Research

---

## Outcome

Designed a user-centric consent experience that improves transparency, builds trust, and gives parents greater control over their child's personal data.
